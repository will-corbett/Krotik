Russian expresses time with a few fixed patterns, each using a particular preposition and case.

## The patterns

| Meaning | Pattern | Example |
|---|---|---|
| on a day | в + accusative | в пятницу |
| in a month | в + prepositional | в январе |
| on (every) Mondays | по + dative plural | по понедельникам |
| in (a time from now) | через + accusative | через неделю |
| (a time) ago | accusative + назад | неделю назад |

After a number, the unit follows the usual number rule: два часа назад, пять лет назад.

## Common mistakes

| Not this | But this | Why |
|---|---|---|
| Я работаю в понедельник. *(meaning every Monday)* | Я работаю по понедельникам. | **Correct, but a different meaning.** в понедельник is one Monday; по понедельникам is every Monday. |
| Я приду после недели. *(meaning in a week)* | Я приду через неделю. | **Wrong.** через is “in” a time from now; после is “after” an event (после урока). |
| в прошлую неделю | на прошлой неделе | **Unnatural.** With неделя, use на + prepositional: на этой неделе, на прошлой неделе. |
